# Prompt Engineering Coding Exercises

**Aadit Joshi** | Agentic AI and Distributed Systems | San José State University | Fall 2026

Three Google Colab notebooks that practice prompt engineering with the Gemini API. Each notebook contains the prompts, the code and the saved outputs, and opens directly in Colab from the badge at the top.

| Exercise | Notebook |
|---|---|
| 1. Prompt Chaining for a Customer Support AI | [Exercise1_Prompt_Chaining_Customer_Support.ipynb](Exercise1_Prompt_Chaining_Customer_Support.ipynb) |
| 2. Code Generation with ReAct Prompting | [Exercise2_ReAct_Code_Generation.ipynb](Exercise2_ReAct_Code_Generation.ipynb) |
| 3. Self-Reflection Prompt for Improving Output | [Exercise3_Self_Reflection_Summary.ipynb](Exercise3_Self_Reflection_Summary.ipynb) |

**Tools:** Google Colab (Python 3), Gemini API via the `google-genai` SDK (free tier), pandas.

**To run a notebook:** add a free Gemini API key as a Colab Secret named `GEMINI_API_KEY`, then Runtime > Run all.
